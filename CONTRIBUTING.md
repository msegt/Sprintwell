# Contributing

Thank you for helping. Sprintwell is AGPL-3.0 licensed; by contributing you agree your work is released under the same licence.

1. Open an issue first for anything bigger than a small fix, so we can agree the approach.
2. Work on a short-lived branch created from an issue, with small commits in the present tense that reference it (for example `Add Kudos column to retro templates (#12)`).
3. Before opening a merge or pull request, run `npm run check` and, for UI changes, `npm run build && npm run test:e2e`.
4. Keep it accessible: keyboard operable, labelled controls, no information conveyed by colour alone.
5. Use British English in the interface and documentation.

Definition of Done for changes: reviewed by someone else, tests passing on SQLite and PostgreSQL, documentation updated.
